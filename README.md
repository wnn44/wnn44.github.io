## ✨ О проекте

**NEON ARCADE** — это веб-платформа с двумя играми: **Тетрис** и **2048**. Всё написано на чистом HTML, CSS и JavaScript — **без фреймворков, без npm, без сборщиков**. Достаточно открыть `index.html` в браузере.

Проект включает:
- 🔐 Собственную систему регистрации и входа (клиентская, SHA-256 через Web Crypto API)
- 🏆 Онлайн-таблицу лидеров на **Supabase**
- 📱 Полностью адаптивный интерфейс (десктоп + мобильные с тач-управлением)
- 🎵 Звуковые эффекты и фоновую музыку (Web Audio API, без аудиофайлов)
- 💾 Локальный резерв рекордов в `localStorage` (на случай недоступности сети)

## 🎮 Игры

### 🟦 NEON TETRIS — `tetris.html`

Полноценный тетрис с современными механиками:

| Механика | Описание |
|---|---|
| **SRS-вращение** | Super Rotation System с wall kicks — как в современных тетрисах |
| **7-bag** | Фигуры выпадают по системе «мешка» — никаких долгих засух |
| **Ghost piece** | Полупрозрачная подсказка, куда упадёт фигура |
| **T-spin** | Определение T-спинов (full и mini) с бонусными очками |
| **B2B** | Back-to-Back бонус за сложные очистки подряд (×1.5) |
| **Combo** | Бонус за последовательные очистки линий |
| **Lock delay** | 500 мс на фиксацию фигуры с 15 «пробуждениями» |
| **DAS/ARR** | Настраиваемое авто-повторение движения (150/45 мс) |
| **Hold** | Отложить фигуру (в планах) |

**Управление:**

| Действие | Клавиши |
|---|---|
| Движение | `←` `→` или `A` `D` |
| Мягкий спуск | `↓` или `S` |
| Поворот по часовой | `↑` или `X` |
| Поворот против часовой | `Z` |
| Сброс (hard drop) | `Space` |
| Пауза | `P` или `Esc` |
| Заново | `R` |
| Звук вкл/выкл | `M` |
| Музыка вкл/выкл | `N` |

### 🟪 NEON 2048 — `2048.html`

Классическая головоломка с неоновыми плитками:

- 🎨 **12 уровней плиток** — от `2` до `2048` и выше (`vsuper`)
- 🎬 **Плавные анимации** — `translate` на GPU, эффекты `merge-pop` и `spawn`
- 👆 **Свайпы** — управление на тач-экранах
- 🖱️ **Мышь** — перетаскивание на десктопе
- ⌨️ **Клавиатура** — стрелки и WASD
- ✨ **Неоновая графика** — градиенты, glow-эффекты через `box-shadow`

**Управление:**

| Действие | Клавиши / Жесты |
|---|---|
| Движение | `← ↑ → ↓` / `W A S D` / свайп / перетаскивание |
| Новая игра | Кнопка **New Game** |

## 🏆 Система лидеров

Все рекорды хранятся в **Supabase** (облачная PostgreSQL-база). Каждая игра пишет в общую таблицу `leaderboards`:

```sql
create table leaderboards (
  id        int8 primary key generated by default as identity,
  game_id   text not null,           -- 'tetris' или '2048'
  username  text not null,
  score     int8 not null,
  date      timestamptz default now()
);
