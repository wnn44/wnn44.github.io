# NEON ARCADE Previews
Поместите сюда медиафайлы для карточек игр:
- `tetris.jpg` / `tetris.gif` / `tetris.mp4`
- `2048.jpg` / `2048.gif` / `2048.mp4`

Параметры видео/изображения прописываются в файле `games.js`:
```js
preview: { type: 'image', src: 'previews/tetris.jpg' } // или 'video', src: 'previews/tetris.mp4'
```
